# Color-Team Signal Patterns

> [!note]
> Use this page when review cycles start surfacing same weaknesses across pursuits. Capture pattern once, reuse many times.

## Repeating signals

- Pink Team keeps asking for evaluator benefit because theme language still sounds internal.
- Red Team flags compliance coverage as present but hard to score.
- Recovery work keeps rewriting prose instead of fixing proof ownership.
- Reviews disagree on win story because discriminators still overlap.

## Response pattern

1. Name review stage where signal appeared.
2. State what evaluator risk it implies.
3. Assign fix lane: capture, proposal, pricing, or proof.
4. Record artifact that will prove risk closed.
