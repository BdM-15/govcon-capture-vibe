Query Tuning

                    

                  

                

                

                  
                  
                

              
              

                

                  Tunes how Capture Chat retrieves context from the knowledge
                  graph. Mirrors the LightRAG WebUI panel and adds a reranker
                  score threshold. Saved per workspace; takes effect on the next
                  query.
                

                

                
              

            


            
            

              
                

                  
                  
                  

                    
Agent Skills Retrieval

                    

                  

                

                

                  
                  
                

              
              

                

                  Controls the briefing book and retrieval pipeline used when
                  any agent skill is invoked against this workspace. Skills go
                  through the same chat-grade hybrid retrieval as Capture Chat
                  (LightRAG aquery_data), then the result is
                  packaged with verbatim source chunks and KG relationships.
                  Saved per workspace; takes effect on the next skill run.
                  Tools-mode hard caps live in the global section below and are
                  backed by .env.
                

                

                
              

            


            

              
                

                  
                  
                  

                    
Global Skill Runtime Caps

                    

                  

                

                

                  
                  
                

              
              

                

                  Global tools-mode ceilings for agent skills. Backed by
                  .env, shared across all workspaces, and used by
                  competitive-intel, compliance-auditor, price-to-win, and other
                  tools-mode skills. Use this for hard stop budgets.
                

                
                
              

            


            
            

              
                

                  
                  
                  

                    
MCP Servers

                    

                  

                

                

                  
                

              
              

                

                  Vendored Model Context Protocol servers under
                  tools/mcps/ are exposed to
                  agent skills that opt in via
                  metadata.mcps: in their
                  SKILL.md frontmatter. No-key MCPs (USAspending, eCFR, GSA
                  CALC+, GSA Per Diem, Federal Register) work out of the box;
                  key-gated MCPs need the API keys set below. Saving keys
                  rewrites .env and
                  triggers a graceful server restart.
