              Query & Skill Tuning Guide
            

            

              Plain-language reference — bookmark mentally, reopen anytime from Settings.
            

          

          
        

        

          

            90-second rule:
            Tune Chunk Top K and
            Max Total Tokens until chat answers feel grounded.
            Skills inherit automatically. Leave advanced panels alone unless something errors.
          


          

            
If this happens… tune this

            

              
                

                  Symptom
                  First knob
                

              
              
                

                  Misses specific RFP wording, tables, long clauses
                  Chunk Top K ↑
                

                

                  Answers feel shallow even with high Top K
                  Max Total Tokens ↑
                

                

                  Misses task areas, factors, big-picture structure
                  KG Top K ↑ · mode mix
                

                

                  Retrieved context feels noisy / off-topic
                  Min Rerank Score ↑ (try 0.2–0.4)
                

                

                  Skill stops with truncation / max turns / timeout
                  Skill Execution Limits (advanced)
                

                

                  “Map everything” / exhaustive workspace ask
                  Auto-boost runs once — still raise Chunk Top K if thin
                

              
            

          


          

            
Query Tuning fields

            

              
Default Mode

              

                mix = KG + RFP chunks (default).
                local = narrow neighborhood.
                global = wide relationship sweep.
                naive = text chunks only.
                bypass = no workspace lookup.
              

              
KG Top K

              
How many graph entities/relationships to rank. Structural breadth.

              
Chunk Top K

              
How many verbatim RFP passages to pull. Usually the most important knob.

              
Max Entity / Relation / Total Tokens

              
Input budget (not answer length). Total is the suitcase; entity/relation are compartments inside it.

              
Enable Rerank / Min Score

              
Second-pass relevance filter. Leave on; raise min score only if context is noisy.

              
Stream / Only Need Context / Prompt

              
Stream = normal chat UX. “Only Need” = debug modes — leave off.

            

          


          

            
Two “similar” skill panels — not redundant

            

              

                Skill evidence packaging (Query Tuning, per-workspace):
                Shapes the briefing book at skill start — what evidence is on the desk before turn 1.
              

              

                Skill Execution Limits → KG tool caps (global .env):
                Limits mid-run fetches when the agent calls
                kg_entities / kg_chunks.
              

              

                Binder on the desk at kickoff vs. extra photocopies during the meeting.
              

            

          


          

            
Skill Execution Limits (when things hard-stop)

            

              
Tool Result Chars

              
Max JSON/text from one built-in tool back to the model. Old 12k often cut entity lists; recommended 50k.

              
Max Read / Write Bytes

              
File size caps on disk (~200 KB read, ~1 MB write). Not retrieval — safety rails for artifacts.

              
Max Turns / timeouts

              
Agent loop length and wait limits. Raise only when skills error on these specifically.

            

            

              If numbers look old (e.g. 12,000 tool chars), that is your saved
              .env — use Reset in Skill Execution Limits for current defaults.
