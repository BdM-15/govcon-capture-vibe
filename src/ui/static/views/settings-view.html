Server Control

Clear LLM cache drops cached responses so the next query re-calls the LLM. Clear documents wipes every document in this workspace (graph, vectors, KV) but keeps the workspace alive — useful when iterating on prompts. Restart server gracefully re-execs the python process; use after editing .env, swapping models, or installing dependencies. The browser reconnects automatically.

Query Tuning

Single retrieval control plane for Capture Chat and agent skills. Skills inherit these settings automatically. Exhaustive prompts (e.g. full workspace maps) receive a one-run coverage boost. Saved per workspace; takes effect on the next chat query or skill run. if field names slip your mind.

Skill Execution Limits (advanced)

Advanced execution ceilings for tools-mode skills (turns, timeouts, tool-output size). Retrieval is configured in Query Tuning above. Defaults are generous; adjust only when a skill run hits a hard stop.

Web Research

Controls skill tools web_search, web_fetch, and web_research. API keys stay in .env (SerpAPI, Olostep, Firecrawl, SearXNG). Per-workspace toggles are stored in ui_web_research_settings.json. Use premium quality on a tool call to force Firecrawl even when it is off in the standard chain.

MCP Servers

Vendored Model Context Protocol servers under tools/mcps/ are exposed to agent skills that opt in via metadata.mcps: in their SKILL.md frontmatter. No-key MCPs (USAspending, eCFR, GSA CALC+, GSA Per Diem, Federal Register) work out of the box; key-gated MCPs need the API keys set below. Saving keys rewrites .env and triggers a graceful server restart.
